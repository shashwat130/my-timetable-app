1. Install Android Studio (free): https://developer.android.com/studio
2. File > Open > choose this planner-android folder. Wait for Gradle sync to finish.
3. Build > Build Bundle(s) / APK(s) > Build APK(s).
4. Click "locate" in the popup: app/build/outputs/apk/debug/app-debug.apk
5. Send that file to your phone and install it (allow "install unknown apps" when asked).
To update the app later: replace app/src/main/assets/index.html and build again.
